# 3D Model Assets

## English

- 3D models will support `.vrm`, `.gltf`, and `.glb` files in the future.
- Integration with three.js and VRM loaders will be implemented in later tasks.
- When bundling model files, the licenses of both the model and the related libraries must be checked.
- Outfit replacement and dress-up features will be considered in later tasks.
- The Chararium model management screen will detect `.vrm`, `.gltf`, and `.glb` files.
- Example path: `assets/models3d/mai/mai.vrm`
- Detected models will be listed, selectable, and display basic information. Actual rendering support will be added in a later task.

## Notes

Model files are not included in this repository by default because each model may have its own license terms.

Place your local model files in this directory when running Chararium locally.
