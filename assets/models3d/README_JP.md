# 3D Model Assets

- 3D モデルは将来的に `.vrm` / `.gltf` / `.glb` を対象にします。
- three.js や VRM ローダーの導入は後続タスクで実装します。
- モデル同梱時は、モデルと利用ライブラリのライセンス確認を必須とします。
- 衣装差し替えや着せ替え機能は後続タスクで検討します。
- Chararium のモデル管理画面では `.vrm` / `.gltf` / `.glb` を検出対象にします。
- 配置例: `assets/models3d/mai/mai.vrm`
- 検出したモデルは一覧・選択・情報表示まで対応し、実描画は後続タスクで追加します。
